# Flight Tools

Flight Bands ([[7. Flight Bands]]) are tied to Power Scale tier, though that doesn't mean flight is entirely locked away from lower-tier characters.

## Buying Access Early to Flight
Any Power Tier can buy flight-granting gear, regardless of whether their tier would naturally grant that Flight Band. Using flight-gear below a level that would naturally grant it tends to drain resources faster than flight is worth. This is intended to ensure flight tools are used sparsely unless in strenuous circumstances.

## The One Exception
Sprite Bonding ([[8. Sprite Bonding]]) removes or reduces this limitation. A strong enough tie to your bonded element makes flying via gear meaningfully cheaper than it would be for a Grounded character.
