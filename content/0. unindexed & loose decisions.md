# Unindexed & Loose Decisions

Companion file to **1. Index - Version 2**. The Index is source of truth for what the handbook contains and where — nothing gets a new handbook file unless it's on that Index. This file exists so that content which was genuinely locked in (or partially decided) somewhere in the Master project, but has no home on the current Index, doesn't just quietly vanish. Everything below was pulled from `0. Version 1` and `Brainstorm` while building the Version 2 handbook.

*(Ch5 World & Geography and Ch6 Reference Content are on the Index but were excluded from this handbook pass by request — not a gap, just out of scope for now.)*

---

## Content with no home on the Index

### Describing a Scene
Currently many references exist that call out to a scene, though what a scene is and how it fits into the system isn't really built out or explained to the reader. This needs to be addressed as it is a very large piece of what ties the mechanics together. This also explains difficulty progression based on scene contents, whether it be narrative driven combat driven or exploration driven.  

### Resource-Interaction Archetypes
9 archetypes, status **Final** in the old Chapter 3 decision log: Builder/Spender, Spend & Recover, Combo Spender, Secondary Resource User, Time-Driven Spender, Overflow/Threshold, Synergistic, Gambler/Volatile, Convert/Transmute. These described the spend-pattern shape of each of the old 20 classes. The source material itself flags this vocabulary as a **design tool that likely won't be needed going forward** — worth confirming whether it's dead, or whether it should resurface as internal design language for Identities (Ch2 §7) even without being player-facing.

### Class Breakdown Template
A 10-hook template (Pool Affinity, PDC, Resource Protection, Fundamental Building Blocks, Dice Stepping Specialty, Scene/Recovery Die Interaction, Crisis Interaction, Elemental Tie-in, Resource-Interaction Archetype, Sprite Bonding) used to keep the old 20-class roster directly comparable. No home now that Classes have been superseded by the Identities + shared Building Blocks system.

### The former 20-class roster
Exalt, Mageblade, Spellwright, Wraithcaller, Farstriker, Bloodmancer, Gloomstalker, Duskrunner, Hexweaver, Cataclyst, Veilrunner, Soulbind, Hallowreed, Bloodguard, Spritebroker, Warcant, Blankstep, Rivenheart, Nexuswalker, Umberlash, plus one parked "Unclaimed" slot. Individual class files (and a later ability-pool trial document built from them) previously existed in the vault under a `Classes` folder; that folder no longer exists. Superseded by **Identities** (Ch2 §7), which independently converged on a similar goal — individual expression without a rigid preset kit — through a different mechanism (drafted signature resource/mechanic instead of a fixed class ability list). Worth knowing this history exists if any specific class's flavor (a Bloodguard's Blood-tanking, a Hallowreed's empty-pool scaling) is ever wanted back as an Identity option.

### First Bonding — cut methods
Archived, not deleted: **Bloodline Oath, Bargain Market, Masked Inheritance, Nameless Path**. All four were explicitly cut from the active 7-method list now in Ch2 §8. Nameless Path specifically was flagged as a clean answer for stragglers/exiles with no cultural backing — a plausible reactivation candidate if that narrative gap is ever felt at the table.

*(Targeting & Aggression Logic, previously listed here, has been reclassified — it's an idea playground, not a locked-in or partially-decided concept, so it doesn't belong in this tracker's scope. It remains out of the Player Handbook regardless, since it's GM-side content either way.)*

## Known cross-reference gaps (topics that exist, but don't yet talk to each other)

Carried forward from an audit pass done against the Speed/Action Economy redesign — these were explicitly named as touched-but-unresolved and still are:

- **Crisis ↔ Action Economy:** does the flat 2-action budget and reaction eligibility still apply once a character is in Crisis (Ch3 §5, §6)? No stated interaction either way.
- **Recovery Die ↔ Speed:** a "spending a Recovery Die bumps your Speed" idea was floated in design conversation but never made it into a written mechanic (Ch3 §7).
- **Flight Bands / Flight Tools ↔ Action Economy:** does changing Flight Band mid-encounter cost an action out of the flat 2 (Ch3 §5, §8, §9)? Unaddressed.
- **Dice-stepping / Pips ↔ Action Economy:** whether stepping a die should ever cost an action, unlock an overflow action, or help cross the reaction threshold — noted as open directly in the Ch3 §5 handbook file itself, repeated here since it's the same underlying gap.
