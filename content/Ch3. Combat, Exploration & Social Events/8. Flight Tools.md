# Flight Tools

Flight Bands ([Ch3. p7](obsidian://open?vault=TTRPG&file=Master%2F1.%20Version%202%2FCh3.%20Combat%2C%20Exploration%20%26%20Social%20Events%2F7.%20Flight%20Bands)) are tied to Power Scale tier, though that doesn't mean flight is entirely locked away from lower-tier characters.

## Buying Access Early to Flight
Any Power Tier can buy flight-granting gear, regardless of whether their tier would naturally grant that Flight Band. Using flight-gear below a level that would naturally grant it tends to drain resources faster than flight is worth. This is intended to ensure flight tools are used sparsely unless in strenuous circumstances.

## The One Exception
Sprite Bonding ([Ch2. p8](obsidian://open?vault=TTRPG&file=Master%2F1.%20Version%202%2FCh2.%20Character%20Creation%20%26%20Development%2F8.%20Sprite%20Bonding)) removes or reduces this limitation. A strong enough tie to your bonded element makes flying via gear meaningfully cheaper than it would be for a Grounded character.
