# Elemental Plane

The Elemental Plane is a second, **overlapping layer of the same reality** — not a separate place you travel to through a portal. Wherever you stand in Reality, the Elemental Plane is already there, layered underneath or alongside it.

## What You Can Rely On

- **Prime proximity is always noticed**, without exception — you cannot be near a Prime Elemental and simply fail to register it.
- **Prime hotspots never need tectonic justification.** This is a standing rule, not an occasional exception the GM grants — a Prime can simply be somewhere, without geological history explaining why.
- Every element in the world carries both a **Planar Behavior** and a **Reality Behavior** description — meaning how an element acts differently on the Elemental Plane versus on the Reality/Physical plane is already fully defined for every element in the game (see the full table in Ch4 §5).

## What Isn't Pinned Down Yet

- General rules for physically crossing between the two planes. The only explicit statement anywhere on this is the Planar element's own Reality Behavior line: *"Crossing planes is difficult and always noticed."* Everything else about plane-crossing is only implied by individual elements' behavior descriptions.
- Whether "always noticed" — Prime proximity and plane-crossing alike — shares one single detection mechanism, or whether these are separate rules that simply happen to use similar language.
- How Metaphysical Weight's "lesser echo on the Elemental Plane" (Ch4 §3) mechanically interacts with a Prime's own passive presence there, if a sacred site and a Prime hotspot ever end up overlapping.
